# TrustShield Project
# TrustShield - Zero Trust Security System for E-commerce SMEs

## Features
- 🔐 Firebase Authentication with TOTP MFA
- 🧑‍💻 RBAC (admin/user roles from PostgreSQL)
- 📜 Access logs with IP tracking (stored in Firestore and MongoDB)
- 🛡️ Suspicious behavior detection (coming soon)

## Technologies Used
- Frontend: HTML + CSS + JS
- Backend: Node.js (Express)
- Database: Firebase Firestore, MongoDB, PostgreSQL

## How to Run
1. Clone repo
2. Run `npm install` in backend
3. Add your Firebase credentials in `.env`
4. Start server with `node server.js`
5. Open `login.html` in browser
